# AssetGuard Backend

The FastAPI backend owns authentication and RBAC, PostgreSQL persistence, telemetry ingestion, condition assessment, operational alerting, maintenance workflows, and optional Gemini analysis.

See the [project README](../README.md) for architecture, local setup, permissions, API groups, migrations, simulator usage, and operational limitations. Interactive API documentation is available at `http://127.0.0.1:8000/docs` while the backend is running.
